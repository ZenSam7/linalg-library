# учебная лаба по плюсам
CMake настроил на сборку этой репы как либу

основной интерфейс и api описан в include/matrix.h

конкретно эта репа (linalg-library) идёт как подмодуль в основной репозиторий [linalg-main](https://github.com/ZenSam7/linalg-main) где есть и тесты, и небольшая демка, показывающая в чём моя либа хороша (относительно привычной реализации)


также добавил сюда в cmake сборку моей либы в питоновскую библиотеку ~~**(зачем?)**~~. пример использования моей c++ либы через питон в файле `linalg_python_library.py` в другой репе: [linalg-main](https://github.com/ZenSam7/linalg-main) . 
P.S. лично я компилирую через mingw на win10, и копирую получившуюся питоновскую либу `.pyd` и интерфейс для IDE `linalg.pyi` прямо в папку к другим либам в окружении в конде (если вы конду не юзаете, то ~~очень сочувствую~~ нейронка скажет как импортировать питоновскую либу в вашем случае)
